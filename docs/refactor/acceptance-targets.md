## 已冻结的测试负载与目标（v1）

| 维度 | 提案 | 测量方法与范围 |
| --- | --- | --- |
| 基本夹具 | 2个企业、每企业2个用户、各2份不同内容同名文档 | 合成资料；权限允许/拒绝用例必须全部通过 |
| 并发负载 | 5个并发运行、总计10个短提示词请求 | 记录模型、时间、输入/输出token及成功数；真实模型与合成故障测试分开 |
| 首token P95 | <=15秒 | 同一测试环境，按nearest-rank计算；网络失败计入失败，不删除慢样本 |
| 总完成耗时 P95 | <=120秒 | 短输入、短回答场景；不推广到长文档/复杂工具任务 |
| 请求超时 | 180秒 | 超时后终态明确，保留可追踪错误和清理证据 |
| 取消 | 请求确认<=1秒；5秒内停止新工具调度 | 不能假定已发给供应商的计算/计费可撤回 |
| 任务租约 | 5秒；每秒检查；故障后10秒内可重领 | 仅用于原型加速故障演练，生产租约需容量验证后调整 |
| 重试 | 可重试故障最多2次；结果不确定的外部写入不自动重试 | 每次保留attempt；认证/权限/格式错误不重试 |
| 上传边界 | 单文件10MiB；首期只验证UTF-8文本 | 超限/不支持格式明确拒绝；不伪称PDF解析已实现 |
| 故障与恢复 | Worker/Host分别崩溃各3次；双Worker竞争3轮 | 任务不丢、终态唯一；有幂等接收方的副作用不重复 |
| 应用回滚 | 60秒内恢复上一原型版本 | A-09受控环境，官网访问连续正常；不代表生产灾备SLA |
| 数据恢复 | 备份恢复到独立数据库并逐项校验夹具 | 不允许以应用回滚代替数据恢复；恢复耗时记录实测 |
| 环境 | Node24.21.0；Linux x64远程Runner及macOS arm64本机 | 记录CPU/内存、OS、数据库/依赖版本；不同环境数据不混为一组 |

权限泄漏、密钥泄漏、未授权副作用、重复业务写入、官网内容回归允许数量均为0。成本记录保留实际/估算/未知三态，不把未知记成0；合成配额拒绝用例用于验证限额机制，不改变用户已批准的真实测试费用策略。
