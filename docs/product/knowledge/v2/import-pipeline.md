# 知识导入与片段解析管线

2026-11-02 · 设计稿 v1 · **planned**。本文定义“知识导入”的后台链路：文件校验、解析、片段化、任务与失败处理。目标不是“上传成功”，而是生成**可定位、可审校、可追溯**的知识片段，进入条目的待审区。音视频为 P2，文本/PDF/DOCX 为 P1；未实现能力不得在 UI 或能力清单中显示为可用。

## 1. 目标

- 支持文本、PDF、DOCX 以及音频、视频的批量导入（分阶段）。
- 每个片段都能回到来源修订与精确位置（行/页/段/时间码），并带 hash、抽取器版本与置信度。
- 解析是持久任务：可恢复、可取消、可重试；失败有稳定错误码，不产生空成功。
- 解析产物不自动发布：片段进入条目待审区，由人接受/修改/合并后才可能进入发布。
- 导入、任务、片段、审校、发布共享现有身份、授权、审批、审计与幂等约束。

## 2. 非目标

- 不做通用 OCR 平台、视频理解、字幕翻译或任意 URL 抓取。
- 不把原始文件、全文或片段明文放进日志、事件或模型提示之外的地方。
- 不允许上传即发布；不允许模型替代审校。
- 首期不做跨空间导入、外部网盘同步、实时协作编辑。

## 3. 文件类型、校验与限制

| 类型 | P1 | P2 | 定位方式 | 备注 |
| --- | --- | --- | --- | --- |
| `text/markdown`、`text/plain` | ✅ | — | 行/段落 | UTF-8；非法编码拒绝 |
| `application/pdf`（文本层） | ✅ | — | 页 + 段落 | 扫描件走 OCR（P2） |
| `application/vnd.openxmlformats-officedocument.wordprocessingml.document` | ✅ | — | 标题/段落/表格降级 | 复杂版式降级为文本并标注 |
| `audio/mpeg`、`audio/wav`、`audio/mp4` | — | ✅ | 时间码 + 说话人（可选） | 外部大模型 ASR 适配器 |
| `video/mp4`、`video/quicktime` | — | ✅ | 时间码 + 关键帧（后续） | 抽取音轨后外部大模型 ASR |
| 图片/扫描件 | — | ✅ | 外部大模型 OCR 页/框 | 测试阶段不启用；未配置时明确失败 |

**通用校验**

- 扩展名 + MIME + magic bytes 三者一致；不一致拒绝。
- 大小、页数、时长、批量文件数、单空间总量按配额校验；超限返回 `QUOTA_EXCEEDED`。
- 拒绝：加密/DRM、宏文档、压缩炸弹、路径穿越文件名、损坏文件、空正文、全空白、纯图片 PDF（转 OCR 状态）。
- 文件名仅用于显示；对象键由服务端生成，不使用用户路径。
- 上传后在隔离区完成病毒/恶意内容扫描；未通过为 `quarantined`，不进入解析。

**建议默认值（可配置，待评审）**：单文件 50MB、PDF 300 页、音视频 2 小时、单批 50 个文件、单空间 5GB；文本正文沿用 v0 的 20,000 字符上限并允许空间调整。

## 4. 导入流程

```text
选择空间 → 上传文件 → 本地预检 → 服务端校验/隔离 → 逐文件元数据
   → 创建批次 → 解析任务（逐文件） → 片段 → 条目待审区
   → 审校 → 发布
```

### 4.1 批次与文件

- `ImportBatch`：一次提交的容器，聚合状态（`parsing/completed/partial/failed/cancelled`）与计数。
- `ImportFile`：单文件状态与失败码；失败不影响同批其他文件（partial）。
- 一个文件一个解析任务；批次不产生“全部成功”假象，逐文件结算。

### 4.2 元数据

逐文件或批量：标题、制度编号、版本、生效/失效日期、来源、语言、可见部门、备注。默认继承空间设置；权限以服务端空间 ACL 为准，不信任前端自报。

- 同空间 `policyCode + version` 已存在 → `SOURCE_VERSION_EXISTS`，提示“新版本/修订”而不是覆盖。
- 同 hash 已存在 → 复用对象，提示重复文件；可选择“新增修订/忽略”。
- 版本单调；生效期不得晚于失效期；未来生效允许，发布时按 `asOf` 过滤。

## 5. 解析管线

### 5.1 阶段

| 阶段 | 动作 | 产物 | 可重试 |
| --- | --- | --- | --- |
| `uploaded` | 对象写入、hash 校验 | 原始对象 | 是（幂等） |
| `validated` | 类型/大小/病毒/加密校验 | 校验结论 | 是 |
| `extracting` | 文本/PDF/DOCX 抽取或 ASR 转写 | 规范化文本 + 结构 | 是（无副作用） |
| `segmenting` | 按标题/段落/页/时间码切分 | 片段候选 + locator | 是 |
| `classifying` | 模型建议概念/关系/条目归属 | 建议（待审） | 是（可跳过） |
| `deduplicating` | 文本 hash/近似重复检测 | 去重标记 | 是 |
| `indexing` | 写入片段、检索索引 | 片段行 + 索引 | 幂等 upsert |
| `pending` | 进入条目待审区 | 待审片段 | — |

任一步失败 → `failed`，保留已完成阶段与诊断；**片段写入前失败不产生半成品**。写入采用事务/幂等键，重试不会重复片段。

### 5.2 片段模型

```json
{
  "fragmentId": "frag-01J...",
  "spaceId": "space-hr",
  "sourceRevisionId": "src-rev-7",
  "locator": {"type": "timecode", "startMs": 750000, "endMs": 790000, "speaker": "HR"},
  "excerpt": "员工入职满一年可享受 5 天年假……",
  "textHash": "sha256:...",
  "language": "zh-CN",
  "confidence": 0.93,
  "extractor": {"kind": "asr", "name": "whisper-local", "version": "1.0.0", "paramsHash": "..."},
  "status": "pending",
  "entryId": "entry-annual-leave",
  "createdAt": "2026-11-02T01:00:00Z"
}
```

定位示例：

| 来源 | locator | 说明 |
| --- | --- | --- |
| Markdown/TXT | `{"type":"line","start":120,"end":134}` | 行号从 1 开始；换行规范化后稳定 |
| PDF | `{"type":"page","page":3,"startBlock":2,"endBlock":5}` | 页 + 段落块 |
| DOCX | `{"type":"paragraph","index":12,"heading":"3.2 年假"}` | 段落索引 + 标题路径 |
| 音频 | `{"type":"timecode","startMs":750000,"endMs":790000}` | 毫秒；可选说话人 |
| 视频 | `{"type":"timecode","startMs":...,"endMs":...,"frame":...}` | 时间码；缩略图后续 |

**约束**：同一来源修订内 locator 唯一；`excerpt` 必须来自原文/转写文本（不得模型改写）；`textHash` 用于去重与漂移检测；无 locator 的片段只能人工创建并标记 `manual`。

### 5.3 外部大模型 ASR/OCR 适配

- ASR/OCR 由外部大模型适配器提供，不自建语音/OCR 引擎；平台统一配置供应商、区域、密钥、保留期与开关，按空间启用并审计。
- **测试阶段只用 DeepSeek 对文本类来源做识别/结构化**（在本地抽取的 Markdown/TXT/PDF 文本层/DOCX 文本上）；不测试音视频/扫描件。DeepSeek 文本模型不承担文件解码或转写，UI/文档/能力清单不得声称已支持。
- 文本类文件解码/抽取在本地完成；音视频/扫描件调用外部适配器，未配置/未批准时返回 `PARSER_UNAVAILABLE`，不降级为假成功。
- 外部调用只发送必要对象或片段；原始文件是否出境按空间审批；密钥只在服务端；结果记录 provider/model/version、置信度与参数 hash。
- 抽取值写入 `extractor` 版本与参数 hash；外部模型/ASR 升级不追溯改历史片段，只影响新解析。

### 5.4 与 Harness 的分工

解析本身是确定性/专用解析器（文本、PDF、DOCX）与外部大模型 ASR/OCR 适配器的工作，不由通用对话模型解码文件；Harness 模型只用于分类、概念/关系建议、摘要等**候选**产出，且经受限工具与只读片段输入调用。任务由持久 Worker 调度，模型凭据只在服务端，片段写入与发布指针不由模型直接操作。来源中的指令视为数据，不能改变抽取规则、权限或审批。

## 6. 任务与可靠性

复用 `product_jobs` / `product_job_events`：

- `kind = knowledge.import.parse`；`idempotencyKey = batchId + fileHash + extractorVersion`；同键同输入返回同一任务，异输入 `IDEMPOTENCY_CONFLICT`。
- 租约/心跳/fencing 沿用现有 Worker；旧 Worker 不能提交过期结果。
- 取消：设置 `cancelRequested`，在阶段边界停止；已写入的片段保留（可删除/忽略），不声称“远端已撤销”。
- 重试：仅未产生副作用的阶段自动重试；片段写入后结果未知 → `unknown`，人工核对，不盲目重放。
- 进度：阶段 + 百分比 + 已生成片段数；SSE/轮询复用任务事件，不新建前端权威状态。
- 批次状态由文件状态聚合，不单独作为权威；批次“完成”不等于已发布。

## 7. 去重、版本与待审区

- **精确重复**：同 hash → 复用对象，提示；不重复解析，除非用户明确“重新解析”。
- **近似重复**：文本 simhash/片段 hash 标记 `duplicateOf`，默认折叠，审校可展开。
- **同名不同 hash**：视为新版本，保留旧修订；不覆盖。
- **待审区归属**：按 `policyCode` + 标题匹配现有条目；无匹配则创建草稿条目壳（无发布指针），片段进入其待审区。模型可建议条目/概念/关系，标记 `suggested`，不自动接受。
- **审校动作**：接受、编辑摘录/元数据、合并相邻、拆分、拒绝（原因）、标记重复、分配概念/关系。全部写审计；`expectedRevision` 防并发覆盖。
- **进入发布的前提**：至少一个已接受片段、条目有有效引用、来源有效、ACL 交集可计算。

## 8. 失败与配额

| 错误码 | 场景 | 用户动作 |
| --- | --- | --- |
| `FORMAT_NOT_SUPPORTED` | 不支持的类型 | 换格式或等待 P2 |
| `FILE_TOO_LARGE` / `PAGE_LIMIT` / `DURATION_LIMIT` | 超限 | 拆分/压缩 |
| `ENCRYPTED_OR_DRM` | 加密/DRM | 去除保护后重传 |
| `MALFORMED_FILE` | 损坏/伪装 | 修复文件 |
| `EMPTY_CONTENT` | 无有效文本（含纯图 PDF） | 走 OCR 或人工录入 |
| `SCAN_REQUIRED` | 扫描件待 OCR | P2 支持后再试 |
| `TRANSCRIBE_FAILED` | ASR 失败/超时 | 重试或人工上传文本 |
| `PARSER_UNAVAILABLE` | 适配器未配置 | 联系管理员 |
| `QUOTA_EXCEEDED` | 空间配额 | 清理/扩容 |
| `CANCELLED` | 用户取消 | 可重新提交 |

配额：文件数、总字节、页数/时长、并发任务、模型调用次数按空间配置；超限在创建批次前拒绝，不先上传再失败。

## 9. 安全与隐私

- 原始文件、转写文本、片段摘录均属私有内容；对象存储私有，下载/预览再验权。
- 解析器在受限进程运行，无外网、无服务器凭据、无 dsh owner 入口；文件名/正文中的指令视为数据。
- 日志只记录 ID、阶段、hash、错误码；不记录全文、转写文本、密钥。
- 事件不带全文；需要内容的消费者按权限拉取。
- 删除/撤回遵循保留策略：来源撤回立即失效引用；物理删除按空间策略与审计，不静默抹历史。

## 10. 页面与交互

- 新建导入 4 步（空间 → 文件 → 元数据 → 提交），支持批量编辑与逐文件覆盖。
- 批次详情：文件表格、阶段进度、片段数、失败码、重试/取消/移除；轮询或 SSE，离开页面不丢任务。
- 上传中关闭页面：任务继续；回来从“我的任务/批次详情”恢复。
- 空态：未选空间、无文件、全部失败、无片段；分别给下一步，不显示假成功。
- 移动端：文件列表转卡片，上传支持系统文件选择；390px 无横向溢出。

## 11. 验收标准

1. P1 三种文本格式各一份合成文件可解析，片段 locator 与原文逐字对应；错误文件返回稳定错误码且无片段。
2. 同一文件重复提交幂等；不同内容同键冲突；任务强杀后可恢复且不重复写片段。
3. 空正文、加密 PDF、超限文件、伪装扩展名全部拒绝，无“成功”记录。
4. 音视频/扫描件（P2）由外部大模型适配器处理：音视频片段带时间码、扫描件带页/框定位；未配置时明确 `PARSER_UNAVAILABLE`，不生成空片段；测试阶段不纳入验收。
5. 片段只能进入待审区，不能直接发布；审校/发布权限负例通过。
6. 跨空间读取片段返回 404/403 且不泄漏标题；原文下载再验权。
7. 批次/任务/片段状态在 Web 与 CLI 一致；未实现能力不注册 ready。
