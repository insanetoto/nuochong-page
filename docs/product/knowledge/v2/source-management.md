# 来源管理：知识空间 / 知识导入 / 知识发布

2026-11-02 · 设计稿 v1 · **planned**。按负责人要求，来源管理拆为三个子模块；空间创建从知识首页移出。本文定义页面、字段、状态与迁移；解析与发布细节分别见 [导入管线](import-pipeline.md) 与 [发布与能力输出](publication.md)。

## 1. 导航与路由

```text
来源管理
├─ 知识空间   /knowledge/manage/spaces
│                /knowledge/manage/spaces/new
│                /knowledge/manage/spaces/:id
├─ 知识导入   /knowledge/manage/import
│                /knowledge/manage/import/new
│                /knowledge/manage/import/:batchId
└─ 知识发布   /knowledge/manage/publish
                 /knowledge/manage/publish/:entryId
                 /knowledge/manage/publish/capabilities
                 /knowledge/manage/publish/quality
```

- 侧栏“来源管理”可展开三子项；当前子项高亮。顶部空间切换保留，但空间切换不改变当前子模块。
- 旧入口：`/knowledge/manage/sources` → `/knowledge/manage/import`；`/knowledge/manage/changes` → `/knowledge/manage/publish`；兼容重定向不丢筛选参数。
- 首页不再有“新建知识空间”表单；空库引导“前往来源管理 → 知识空间”。

空间是**业务知识域**（如人力资源制度、财务报销），不是部门本身；部门只决定可见范围，多个部门可共用一个空间，一个部门也可关联多个空间。

## 2. 知识空间

### 2.1 列表

```text
知识空间                                      [+ 新建空间]
[搜索空间…] [部门 ▾] [状态 ▾]
┌──────────────────────────────────────────────────────────────────────────┐
│ 人力资源制度    HR-POLICY   部门：人力资源部   条目 42 · 来源 18 · 待审 3  │
│ 负责人 张三 · 更新 2026-10-30                            [设置] [归档]    │
├──────────────────────────────────────────────────────────────────────────┤
│ 财务报销        FIN-POLICY  公司公共          条目 26 · 来源 11 · 待审 0  │
└──────────────────────────────────────────────────────────────────────────┘
```

列/卡片字段：名称、编码、业务域类型、部门范围、条目数、来源数、待审数、负责人、状态、更新时间。默认按最近更新排序；空库显示创建引导，不显示示例空间。

### 2.2 新建向导（3 步）

| 步骤 | 字段 | 校验/说明 |
| --- | --- | --- |
| ① 基本信息 | 名称、编码、描述、业务域类型 | 编码公司内唯一、创建后不可改；名称可改；类型：制度/主题/FAQ/混合 |
| ② 可见范围 | 公司公共 / 指定部门（多选）、是否包含下级部门 | 部门必须存在且启用；默认不继承子树；放宽可见性需审批 |
| ③ 角色与默认值 | 负责人、编辑、审校、发布人；默认有效期；导入上限；保留策略；只读显示自批策略 | 角色来自共享授权；负责人必须是成员；新空间默认禁止自批；豁免仅走独立治理命令 |

提交前预览：将创建的空间、可见部门、角色绑定、默认配额与影响；确认后调用 `knowledge.spaces.create.v1`（扩展输入，保持向后兼容），服务端写审计与 outbox。

### 2.3 设置与生命周期

- **可改**：显示名（允许改名，旧链接按 code 保持稳定）、描述、部门范围（需影响预览与审批）、角色、配额、默认有效期、发布策略（`allowSelfPublish` 不允许通过普通设置修改，见下节）、归档状态。
- **不可改**：编码、创建人、历史发布记录。
- **归档**：停止新导入/发布；历史仍按权限可读；有运行中任务时先取消或等待；不物理删除。
- **转移负责人**：需当前负责人 + 管理员确认，写审计；不自动转移发布权限。
- **删除**：仅空空间可删（无来源、无条目、无发布）；否则只能归档。

### 2.4 自批豁免的受控策略

`allowSelfPublish` 默认 false，不能由空间负责人/发布人通过普通设置或创建空间输入直接开启。仅服务端登记为 `single-user` 或 `demo` 的空间可申请；标记由平台治理维护，客户端、模型和普通空间负责人不能自行变更。正式关键制度空间不允许开启；类型变更或迁入正式用途时先关闭豁免并重新审查。

候选命令 `knowledge.spaces.publication-policy.set.v1` 独立处理策略：平台管理员身份 + 全局共享 `access:manage`，并由另一名具备同等治理权限的人员批准（申请人不可自批策略）。内容发布权限不赋予策略管理权；没有第二位治理批准人时保持关闭，不引入启动参数或 UI 绕过。单人指内容工作流可由一人完成，不代表免除平台策略治理。

输入包含 spaceId、allowSelfPublish、reason、expectedPolicyRevision、idempotencyKey、approvalId；启用/关闭均审批并审计。审批绑定策略变更 hash、空间类型及 policyRevision；与策略写入在同一事务校验/消费并增加 policyRevision。内容发布审批同时绑定 policyRevision，策略变化后旧内容审批失效；排期任务执行前再次校验。策略历史不可改写。

负例：仅有知识发布权限者不能开豁免；普通 settings/create 输入夹带 allowSelfPublish 返回 INVALID_INPUT；未获批准、申请人自批、非合格空间、过期审批、旧策略版本和并发写入全部拒绝且无副作用。Web/API/CLI/MCP 同权，受限 MCP 默认不开放此治理命令。

### 2.5 权限

| 动作 | 权限 |
| --- | --- |
| 查看列表/详情 | `knowledge:read`（可见空间） |
| 创建空间 | `knowledge:publish`（全局）+ 审批（首期沿用） |
| 修改设置/归档 | 空间负责人 + `knowledge:publish`（空间）或平台管理员 |
| 管理部门范围/角色 | 共享 `access:manage` 或空间负责人受委托范围 |

拒绝返回 403/404 按防枚举策略；UI 隐藏按钮不等于服务端放行。

## 3. 知识导入

### 3.1 批次列表

```text
知识导入                                        [+ 新建导入]
[空间 ▾] [状态 ▾] [时间 ▾]
批次 B-20261102-01  人力资源制度  5 个文件  解析中 3/5  [查看]
批次 B-20261101-03  财务报销      2 个文件  部分失败 1   [查看] [重试失败项]
```

字段：批次号、空间、文件数、成功/失败/处理中、创建人、时间、状态。失败项可重试；取消只停止未完成项，已生成片段保留（可删除/忽略）。

### 3.2 新建导入（4 步）

1. **选择空间**：只能选有 `knowledge:edit` 的空间。
2. **上传文件**：多选；显示格式/大小/时长限制；拖拽或选择；上传前本地预检扩展名与大小（服务端仍复检）。
3. **文件元数据**：逐文件或批量填写标题、制度编号、版本、生效/失效日期、来源、语言、可见部门；默认继承空间设置；同名/同编号提示“新版本”而非覆盖。
4. **提交解析**：确认文件 hash、预计任务数与配额；创建批次和解析任务，跳转详情跟随进度。

### 3.3 文件详情与失败

每个文件显示：文件名、类型、大小、hash、阶段、进度、失败码、片段数、进入待审的条目。失败码示例：`FORMAT_NOT_SUPPORTED`、`FILE_TOO_LARGE`、`ENCRYPTED_OR_DRM`、`MALFORMED_FILE`、`SCAN_REQUIRED`、`TRANSCRIBE_FAILED`、`EMPTY_CONTENT`、`QUOTA_EXCEEDED`、`CANCELLED`。失败不产生“成功”片段；空正文不得写入。

### 3.4 文件类型与阶段

| 类型 | P1 | P2 | 说明 |
| --- | --- | --- | --- |
| Markdown / TXT | ✅ | — | UTF-8；沿用 v0 上限，可配置 |
| PDF（文本层） | ✅ | — | 按页/段落定位；扫描件转 OCR 待 P2 |
| DOCX | ✅ | — | 标题/段落定位；复杂表格降级为文本 |
| 音频 mp3/wav/m4a | — | ✅ | 外部大模型 ASR 适配器 + 时间码片段 |
| 视频 mp4/mov | — | ✅ | 抽取音轨后外部大模型 ASR；关键帧/画面文字后续 |
| 图片/扫描件 | — | ✅ | 外部大模型 OCR；测试阶段不启用 |

音视频/扫描件通过外部大模型 ASR/OCR 适配器接入，平台统一配置供应商、密钥与数据边界；**测试阶段只用 DeepSeek 对文本类来源做识别/结构化**，音视频/扫描件不纳入测试，未配置时明确失败，不以“已支持”展示。

## 4. 知识发布

### 4.1 待审队列

```text
知识发布
[待审 9] [待发布 2] [已发布] [能力输出] [质量检查]
┌──────────────────────────────────────────────────────────────────────────┐
│ 年假制度        人力资源   片段 12 待审  草稿 v5   更新 10:20  [审校]     │
│ 报销标准        财务       片段 4 待审   草稿 v2   更新 09:05  [审校]     │
└──────────────────────────────────────────────────────────────────────────┘
```

- 队列项来自导入片段和手工草稿；显示片段数、草稿版本、阻塞项（缺引用/来源失效/冲突）。
- 支持按空间、责任人、状态筛选；批量操作仅限同空间且逐项校验。

### 4.2 条目审校（三栏）

```text
┌──────────────┬───────────────────────────────────────┬──────────────────────┐
│ 条目结构      │ 正文草稿                                │ 依据与影响            │
│ 1 适用范围    │ 员工入职满一年可享受 5 天年假… [1]      │ 片段 1 视频 12:30–13:10│
│ 2 天数        │ 司龄每增加一年增加 1 天… [2]            │ 片段 2 制度 PDF 第 3 页│
│ 3 申请流程    │ 通过 OA 提交… [3]                       │ 来源有效期 2026-01-01  │
│ + 新增章节    │ [插入引用] [AI 建议] [预览]              │ 可见范围/ACL 交集      │
│              │                                         │ 影响：搜索/问答/课程   │
└──────────────┴───────────────────────────────────────┴──────────────────────┘
[退回] [保存草稿] [提交审校] [发布]（按权限与状态显示）
```

- 左侧结构：章节/段落；支持拖拽排序、合并/拆分。
- 中间正文：纯文本安全渲染；引用角标定位片段；AI 建议只生成草稿，需人工采纳。
- 右侧：逐条片段（locator、摘录、置信度）、来源状态、ACL 交集预览、受影响能力/课程、审校 hash。
- 阻塞项常驻顶部：缺引用、来源过期、跨空间证据引用、冲突未处理、审批失效。
- 并发：`expectedRevision`；冲突保留本地草稿并提示合并，不 last-write-wins。

### 4.3 发布与能力输出

发布中心显示目标条目/版本、生效时间、可见范围、受影响能力与课程、不可逆影响；审批后 CAS 发布。能力输出页列出 `search/answer/graph/api/cli/mcp/export` 的状态、版本、消费者、配额、契约与测试入口；消费者不设产品级白名单/数量上限（设计），但必须注册、使用受限凭据、可审计、可撤销，配额可配置、默认不限。详见 [发布与知识能力输出](publication.md)。

### 4.4 质量检查

首期把质量检查放在发布模块内：死链/缺引用/来源过期/孤立条目/冲突/长期未复核。阻断项不能跳过；语义冲突只提示证据，由人裁定。质量结果不另建独立产品菜单，避免与“发布前检查”两套规则。

## 5. 状态矩阵

### 5.1 空间

| 状态 | 可导入 | 可发布 | 员工可读 | 说明 |
| --- | --- | --- | --- | --- |
| active | ✅ | ✅ | 按 ACL | 正常 |
| read-only（配额/策略） | ❌ | ❌ | ✅ | 超配额或管理员冻结 |
| archived | ❌ | ❌ | ✅（历史） | 不删除历史 |

### 5.2 导入文件

`uploaded → validated → parsing → parsed / failed / quarantined / cancelled`；`parsed` 只表示片段已生成，不代表已审核或发布。

### 5.3 条目

`draft → pending_review → reviewed → published → withdrawn / superseded`；`stale` 是发布后依据失效的派生状态，不是人工设置。

### 5.4 发布

`draft_plan → approved → scheduled → published → withdrawn / superseded`；失败保留原现行版本，不产生半发布。

## 6. 权限与安全

- 导入、编辑、审校、发布分别校验；默认审校人不能独自发布；豁免空间必须显式配置并审计。
- 上传文件在隔离区校验；解析任务不携带服务器凭据；模型只读授权片段。
- 原文下载/预览再次验权；片段摘录也按来源 ACL 过滤。
- 批次、文件、失败码、片段计数不向无权用户泄漏。
- 所有写操作幂等键 + 审计；发布/撤回/能力启停必须审批，`--yes`/dry-run 不能绕过。

## 8. 验收标准（设计验收）

1. 首页无创建空间入口；空库引导到知识空间；有权限用户可在 3 步内完成创建并看到审计记录。
2. 空间编码重复、部门停用、无权限创建、未豁免的自批发布均被拒绝且无副作用。
3. 一次导入可包含多文件；失败文件有稳定错误码与重试；空解析不产生成功片段。
4. 片段进入条目待审区；审校人可接受/退回/合并，发布人不能跳过审校。
5. 发布后能力输出页显示能力状态；撤回后搜索/问答/图谱同步失效。
6. 390px、键盘、空态/错误/权限变化状态可用；不出现个人 Key 或原生 owner 入口。
7. Web/CLI 对同一空间、批次、条目的状态与错误码一致。
