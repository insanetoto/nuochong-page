## 联合验收必须跑的场景

1. 员工登录→知识全景→筛选/聚焦→条目→引用原文；维护者从空库引导进入空间管理，首页无创建表单。
2. 管理者建空间→逐类文本导入→片段审校→条目修订→独立审批发布→图谱/搜索/问答读取同一有效快照。
3. 撤回来源/撤销权限→图谱、搜索、问答、下载与打开的引用不继续披露；旧审批/缓存不绕过校验。
4. 解析失败重试、发布并发冲突、取消/断线/重启恢复→不重复副作用、持久唯一终态；未知远端结果先核对。
5. 旧v0页面或缺图谱组件、缺任一三来源子模块、artifactDigest/SHA错误、必选证据缺失、人工验收缺失时，V2发布检查明确失败。

第5项是防止本次问题重现的门禁负例，不能只测试新页面正常路径。测试运行结果与设计清单分开；模块CI绿不代表上述场景通过。
