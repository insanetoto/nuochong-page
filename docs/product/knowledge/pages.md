## 设计原则与布局

独立产品壳与官网分离。桌面采用左侧产品/知识导航（约 216px）、中间主内容（流式最大 1200px）、按需右侧引用/影响抽屉（约 340px）；顶部为面包屑、当前空间、全局检索、任务与个人菜单。手机侧栏收起为抽屉，列表转卡片，引用以全屏详情展开；主操作高度至少 44px，键盘可达、可见焦点，状态不能只用颜色表达。

风格以官网 `app/globals.css` 和 `app/HomePage.tsx` 为依据：白色/浅蓝底、品牌蓝主操作、青色辅助点缀、深蓝正文，使用官网品牌标志、字体栈、圆角与柔和阴影。产品侧栏使用白底与浅蓝选中态，保持长时间阅读的清晰度；标题与正文建立层级，正文 16px、行高约 1.7。引文、日期、版本和状态常驻，避免只有聊天框没有知识内容。所有权限由 API 决定，隐藏按钮不能代替拒绝。

产品切换为企业知识库 / 企业 AI 工具 / 培训和考试。未实现产品展示“规划中”与范围说明，不创建模拟可用页面；原生 Harness 管理员演示单独入口。公司模型统一供给，员工页面没有 DeepSeek 登录、API Key 输入或原生 owner 管理入口。

## 统一组织与权限入口

侧栏增加“统一管理 → 组织与权限”，跳到共享插件页面，不在知识库内部再建部门、人员或角色模块。共享页面包含部门树、成员/调岗/停用、角色权限目录和产品资源范围绑定；知识库、工具、培训的菜单均进入同一管理入口，保留 productId 筛选。该页同样使用官网蓝白主题；原型展示合成组织和三产品角色边界，写操作均保持 planned。

## 页面详细交互

### A. 知识首页与搜索

顶部“搜索制度或提出问题”，默认搜索；显式“AI 问答”按钮切换到问答，避免一次普通搜索消耗模型。下方以制度分类和主题导航承载浏览；更新列表显示“何时生效”，不将上传时间当生效日期。搜索按 relevance 排序，支持编号精确查询、中文同义词和空结果建议；过滤条件同步 URL，浏览器前进/后退恢复筛选。

### B. 知识正文与引用

标题区固定显示“现行/即将生效/已失效/候选”、知识版本和最近核验日期；正文开头写明“AI 整理，制度原文为准”。每条结论的来源角标打开右抽屉：文件/编号/版本/生效期/条款定位与原文链接。关联页按权限过滤；草稿预览与员工视图清晰区分。反馈按钮选择“引用错误/内容冲突/已过期/其他”并提交理由，不能直接改正式页。

### C. 有依据问答

输入区支持空间和“当前有效”范围；提交后以任务进度替代空白等待。完成卡包含答案、可展开引用、证据时间和冲突警告。无依据时显示“当前可访问制度中未找到充分依据”，给建议检索词；冲突时并列两个有权来源，不擅自选规则。停止跟随不声称远端已取消；“取消任务”另调用取消命令并跟踪终态。答案保存私有，只有内容维护者才可创建“沉淀候选”任务，仍需审校发布。

### D. 导入、编译与审校

上传前显示格式/大小及扫描件暂不支持；元数据含唯一制度编号、归口、版本、生效/失效日期、来源和可见空间。前后版本有差异对比，解析片段可定位原文。编译任务完成后不是“自动发布成功”，而是“生成候选变更”。审校页常驻变更集 hash、baseSnapshot、影响范围；引用缺失或冲突未处理时禁用发布，同时显示服务端阻断原因。两个编辑者冲突时保留各自草稿，刷新合并后重审。

### E. 发布和质量维护

发布确认页显示当前与目标版本、时间、可见范围、失效页面/课程引用和不可逆影响，提交后使用相同幂等键避免重复发布。撤回后员工立刻不能再引用相关版本，维护者可见审计。质量中心按“阻断/待复核/建议”分组；LLM 检测到制度冲突仅提出问题和证据，由内容负责人裁定。

### F. 集成与异常

连接器仅显示已实现类型；未知或未安装类型为 planned。同步异常分可重试、权限失效和未知远端结果；不提供一键盲目重放所有写入。错误含 requestId、可恢复动作和保留输入提示，不弹出模型登录/个人 Key 页面。服务不可用显示“公司演示模型暂不可用，请联系管理员”。401 返回公司登录页，403 显示无权，404 不确认敏感资源存在。

## 必须评审的状态矩阵

| 场景 | 员工可见 | 维护者可见 | 验证点 |
| --- | --- | --- | --- |
| 空库 | 创建后可见的引导，无虚假数量 | 导入入口 | 空结果不造示例业务数据 |
| 网络/模型不可用 | 保留输入、明确失败和重试 | 失败码和任务 ID | 不引导个人 Key、不记成功 |
| 来源已撤回 | 依据不可用提示，重新检索 | 影响页清单 | 旧缓存/下载/问答都不能绕过 |
| 权限被撤销 | 内容隐藏并终止返回 | 有权的脱敏审计 | 无旧正文闪现和敏感标题泄漏 |
| 发布并发冲突 | 保持原现行页 | 对比 baseSnapshot/重新审校 | 不覆盖新版本 |
| 移动端与键盘 | 导航、引用、搜索可完整使用 | 核心维护操作可达 | 390px 无横向溢出、焦点可见 |

## 原型验收范围

原型可点击切换首页/搜索/阅读/问答/来源/审校/质量/集成/统一组织与权限；可从搜索或问答进入引用阅读，所有样例均标注合成。原型的示例答案为评审文案，不调用模型，也不声称真实业务执行成功。正式 UI 任务须接入业务 API 并通过权限负例与可访问性验证，不能把此原型计作完成页面开发。
