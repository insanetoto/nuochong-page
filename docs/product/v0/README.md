## 初版范围与默认建议

- 单公司、共享部门/成员、固定产品角色模板；权限绑定到知识空间；公司账号/密码或管理员签发的受限公司凭据，不接受模型 Key 作为身份，不接原生 owner。
- 首版 Markdown/TXT（UTF-8，单份正文最多 20,000 字符）；对象存储先用私有本机内容寻址适配，数据库为 PostgreSQL，不以内存或浏览器存储替代权威状态。
- raw 不可变；Harness 输出候选知识，校验引用后人工审核/发布；现行知识可浏览、中文关键词检索、附原文版本引用的问答。AI 不自动发布制度。
- 首版固定空间级角色与可见范围；首版只接受同一空间的来源编译，跨空间混合引用拒绝；细分来源 ACL 和跨空间权限交集扩展留待下一轮。版本/有效期/撤回实时生效。
- 第一方插件组合；AI 工具与培训入口明确 planned，不开发它们的业务；公共人员/部门/角色模型为未来两产品复用。
- 每项已交付能力同时有 v1 commandId、输入/输出 schema、HTTP/CLI 映射；MCP 只公开已有受限能力，不自动公开组织和授权写操作。

## 已实现操作入口

实际工作台：`/oa-test/product/`（已部署并通过真实公网验证），静态页面原型仍保留作设计参考。部署和私有数据/模型/备份/回退见 [运行手册](../../../apps/control-api/deploy/product/README.md)；[验证记录](validation.md)区分真实模型与合成测试。

工作顺序：公司账号登录 → 管理员创建公共或部门空间并授权 → 导入 UTF-8 Markdown/TXT → 选择 1–3 个来源编译 → 编辑草稿与逐行引用 → 明确审校 → 申请精确内容审批并发布 → 员工搜索/浏览/引用问答。使用既有公司模型，页面不索要个人 Key。
