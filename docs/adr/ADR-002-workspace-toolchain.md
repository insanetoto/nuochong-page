# ADR-002：单仓库与工具链

状态：Accepted（2026-10-29，用户明确批准A-10 Go；采纳为B阶段架构基线，不代表生产能力全部交付）。

## 已采纳决策

采用npm workspaces目标结构，保持当前npm生态；Host原型固定Node24.21.0与CLI/SDK0.2.1-rc.2。

## 备选与取舍

原提案pnpm只是候选；本次不为形式一致增加包管理迁移。多仓库会使契约与测试同步更困难。

## 边界与后果

现阶段根项目仍Node22 CI；B-01/B-06再统一经过验证的工作区Node版本，不能仅因Host测试通过就直接更改旧生产。所有锁文件提交，禁止浮动latest。

## 证据与验收

A-04独立npm ci及macOS/Linux启停已通过；B-01再验证工作区构建和Node迁移。

## 变更或撤回

若验证不满足冻结指标，记录失败与替代实验并修订此ADR；不偷偷更换接口、版本或验收标准。破坏性变化必须带迁移/兼容方案。

## A-10最终采纳记录

用户在当前会话明确回复“批准 A-10 Go”。采纳npm workspaces方向与已验证的Host Node24.21.0/SDK0.2.1-rc.2；当前旧root/Node22流水线不自动改变，B-01/B-06再迁移并验证。证据与遗留责任见[阶段评审](../refactor/phase-a-review.md)；后续改变版本、边界或冻结指标须独立记录并重测。
