# ADR-007：身份与企业隔离

状态：Proposed；A-05待确认技术基线，A-06—A-09实测后由A-10判断是否最终接受。

## 决策提案

生产接入OIDC身份提供方；业务服务构造可信ActorContext，每个资源操作绑定企业。首发单企业，测试至少两个企业。

## 备选与取舍

不沿用前端演示口令；不自行建设完整密码找回体系。外部OIDC供应方尚未指定，不虚构已有账号服务。

## 边界与后果

客户端创建运行的schema不允许tenantId/userId/roles；API验证会话后注入。工具能力绑定资源/动作/有效期，执行时重新授权。A-08使用合成签名身份验证隔离，不能冒充生产IdP联调。

## 证据与验收

A-08签名/issuer/audience/过期/撤权与跨企业负例；B-02实际IdP对接。若外部IdP不可用，明确阻断真实登录而非回退演示认证。

## 变更或撤回

若验证不满足冻结指标，记录失败与替代实验并修订此ADR；不偷偷更换接口、版本或验收标准。破坏性变化必须带迁移/兼容方案。
