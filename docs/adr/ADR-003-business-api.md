# ADR-003：业务API与前端

状态：Accepted（2026-10-29，用户明确批准A-10 Go；采纳为B阶段架构基线，不代表生产能力全部交付）。

## 已采纳决策

官网保留React/Vite；工作台逐步迁离Worker依赖。业务API采用Fastify5.12.7；自有JSON契约不依赖HTTP框架。

## 备选与取舍

继续vinext完整承载可过渡，但会延续测试/生产范围差异；本期不引入微服务网关。

## 边界与后果

HTTP接口负责认证、资源授权、幂等、事务和错误映射；SDK仅在服务端适配层使用。前端通过业务API获取执行流，不直接连接完整Harness管理界面。

## 证据与验收

版本已通过元数据核验及A-09真实HTTP/受控部署验证，见部署报告；完整业务API和生产入口仍由B阶段实现并验收。

## 变更或撤回

若验证不满足冻结指标，记录失败与替代实验并修订此ADR；不偷偷更换接口、版本或验收标准。破坏性变化必须带迁移/兼容方案。

## A-10最终采纳记录

用户在当前会话明确回复“批准 A-10 Go”。A-09已实际验证Fastify5.12.7及HTTP代理。必须关闭removeAdditional/coerceTypes/useDefaults等静默改写，伪造身份字段返回400且无入库副作用。保留React/Vite官网基线。证据与遗留责任见[阶段评审](../refactor/phase-a-review.md)；后续改变版本、边界或冻结指标须独立记录并重测。
