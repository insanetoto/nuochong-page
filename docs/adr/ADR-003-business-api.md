# ADR-003：业务API与前端

状态：Proposed；A-05待确认技术基线，A-06—A-09实测后由A-10判断是否最终接受。

## 决策提案

官网保留React/Vite；工作台逐步迁离Worker依赖。业务API候选Fastify5.12.7；自有JSON契约不依赖HTTP框架。

## 备选与取舍

继续vinext完整承载可过渡，但会延续测试/生产范围差异；本期不引入微服务网关。

## 边界与后果

HTTP接口负责认证、资源授权、幂等、事务和错误映射；SDK仅在服务端适配层使用。前端通过业务API获取执行流，不直接连接完整Harness管理界面。

## 证据与验收

候选版本已通过npm元数据核验；实际HTTP原型/部署由A-08/A-09验证，未实测前不声称生产选型已验收。

## 变更或撤回

若验证不满足冻结指标，记录失败与替代实验并修订此ADR；不偷偷更换接口、版本或验收标准。破坏性变化必须带迁移/兼容方案。
