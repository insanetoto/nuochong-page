# ADR-006：持久任务与幂等

状态：Proposed；A-05待确认技术基线，A-06—A-09实测后由A-10判断是否最终接受。

## 决策提案

业务库任务表＋独立Worker；以租约、重试、唯一幂等键和终态仲裁管理执行。

## 备选与取舍

专用Redis队列后续可替换；不以Harness会话日志代替业务任务恢复机制。

## 边界与后果

queued→running→succeeded/failed/cancelled；租约失效进入retry_wait再排队。取消请求与结果终态分离。外部写入用稳定幂等键；结果不确定时人工核对，不能泛称任何远端都exactly-once。

## 证据与验收

A-07双Worker、崩溃、取消/完成竞争、重复请求与有幂等接收方的副作用测试；A-09联合恢复。

## 变更或撤回

若验证不满足冻结指标，记录失败与替代实验并修订此ADR；不偷偷更换接口、版本或验收标准。破坏性变化必须带迁移/兼容方案。
