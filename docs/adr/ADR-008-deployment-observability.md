# ADR-008：部署、追踪与恢复

状态：Accepted（2026-10-29，用户明确批准A-10 Go；采纳为B阶段架构基线，不代表生产能力全部交付）。

## 已采纳决策

官网静态产物独立；API/Worker/Host作为独立受管理Node进程或容器；新测试/生产推广同一不可变产物。

## 备选与取舍

旧Cloudflare测试应用保留到替代环境验收；不把Linux启动测试称为公网测试环境部署完成。

## 边界与后果

关联requestId/runId/sessionId与版本清单；Host故障对官网隔离；应用回滚和数据恢复分开。PR/CI保护已生效，用户明确批准必需review人数为0；生产推广仍需明确授权。

## 证据与验收

A-09本地/受控环境进程与代理演练；B-06实际发布门禁与产物推广；E阶段完整灾备。不修改现有生产配置。

## 变更或撤回

若验证不满足冻结指标，记录失败与替代实验并修订此ADR；不偷偷更换接口、版本或验收标准。破坏性变化必须带迁移/兼容方案。

## A-10最终采纳记录

用户在当前会话明确回复“批准 A-10 Go”。A-09受控容器的同image ID推广、整体回滚、独立数据库恢复、官网隔离及资源探针通过。v1/v2仅内嵌release清单不同，不代表破坏性代码/迁移回滚或生产灾备；真实公网入口、统一必需gate与生产批准由B-06/B-08落实。证据与遗留责任见[阶段评审](../refactor/phase-a-review.md)；后续改变版本、边界或冻结指标须独立记录并重测。
