# ADR-001：产品与执行边界

状态：Accepted（2026-10-29，用户明确批准A-10 Go；采纳为B阶段架构基线，不代表生产能力全部交付）。

## 已采纳决策

官网独立静态发布；工作台与管理共用前端；业务API采用模块化单体；Harness Host独立进程。

## 备选与取舍

全面微服务会增加当前运维负担；把业务全部放Host会扩大上游变更影响。

## 边界与后果

身份、企业、知识、培训、工单、任务终态归业务平台；Host会话仅为执行证据，通过runId关联。官网不依赖API/Host可用性。

## 证据与验收

A-09停Host仍可访问官网；B-01保护基线；B-06独立产物发布。

## 变更或撤回

若验证不满足冻结指标，记录失败与替代实验并修订此ADR；不偷偷更换接口、版本或验收标准。破坏性变化必须带迁移/兼容方案。

## A-10最终采纳记录

用户在当前会话明确回复“批准 A-10 Go”。采纳模块化单体业务后端、独立Worker/Host与静态官网隔离；业务库权威。A阶段为边界原型，不表示业务模块已经产品化。证据与遗留责任见[阶段评审](../refactor/phase-a-review.md)；后续改变版本、边界或冻结指标须独立记录并重测。
