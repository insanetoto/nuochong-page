# ADR-005：业务存储与检索

状态：Accepted（2026-10-29，用户明确批准A-10 Go；采纳为B阶段架构基线，不代表生产能力全部交付）。

## 已采纳决策

业务库候选PostgreSQL17.11，Node客户端pg8.23.1；文件经S3兼容存储接口访问。向量检索在C阶段验证后决定pgvector扩展版本。

## 备选与取舍

SQLite仅适合单进程原型，不能作为本次并发任务验收证据；独立向量数据库暂不引入。

## 边界与后果

认证基础表由B-02先落地，B-03扩展通用存储；迁移由单步骤管理。对象路径与业务资源绑定企业。检索权限在服务端过滤，文件下载再次授权。

## 证据与验收

PostgreSQL17.11来自官方支持分支文档；A-07使用真实数据库验证事务/租约，B-03验证恢复。当前本机无Docker/psql，不伪造已部署数据库。

## 变更或撤回

若验证不满足冻结指标，记录失败与替代实验并修订此ADR；不偷偷更换接口、版本或验收标准。破坏性变化必须带迁移/兼容方案。

## 发布版本依据

[PostgreSQL17官方文档](https://www.postgresql.org/docs/17/index.html)标示17.11；仅核验候选版本，尚未安装或压测。Node客户端版本通过npm官方registry核验。

## A-10最终采纳记录

用户在当前会话明确回复“批准 A-10 Go”。PostgreSQL17.11/pg8.23.1的真实并发/恢复及独立数据库备份恢复已验证。S3兼容接口为B-03实现方向，真实存储供应商仍待接入；pgvector/Embedding版本在C阶段另行冻结，未虚构已经验证。证据与遗留责任见[阶段评审](../refactor/phase-a-review.md)；后续改变版本、边界或冻结指标须独立记录并重测。

2026-10-29起，公司OA以Harness为基座。本文保留已验收技术决策历史；旧业务迁移义务和B—E阶段产品范围由[ADR-010](ADR-010-oa-harness-product-scope.md)及[新路线图](../refactor/roadmap.md)替代，不自动恢复旧业务模块。
